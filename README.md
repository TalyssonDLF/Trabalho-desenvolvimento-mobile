# LojaVisualAndroid

Projeto demonstrativo para trabalho de Desenvolvimento Web/Mobile no Android Studio.

## Telas
1. Home com 4 produtos clicáveis.
2. Detalhes do produto com quantidade e botão Comprar agora.
3. Pagamento visual com Cartão/PIX e confirmação demonstrativa.

## Como abrir
1. Extraia o ZIP.
2. Abra o Android Studio.
3. Clique em **Open** e selecione a pasta `LojaVisualAndroid`.
4. Aguarde o Gradle Sync. Se o Android Studio pedir o SDK 35 ou JDK 17, aceite a instalação/configuração sugerida.
5. Crie/inicie um emulador Android e clique em **Run ▶**.

Nenhum pagamento é real e não há backend/banco de dados.
